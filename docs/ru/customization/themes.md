# Пользовательские темы

MultiAI CLI может использовать встроенную цветовую схему или пользовательский файл темы в формате JSON. Пользовательские файлы хранятся в каталоге тем и отображаются в `/theme` рядом со встроенными вариантами.

## Встроенные цветовые токены

Пользовательские темы могут переопределять перечисленные ниже токены. В столбцах `dark` и `light` указаны встроенные значения; вариант `auto` при запуске выбирает одну из этих палитр, а если определить фон терминала не удаётся, использует `dark`.

| Токен | `dark` | `light` | Что он задаёт |
| --- | --- | --- | --- |
| `primary` | `#4FA8FF` | `#1565C0` | Самый часто используемый цвет: ссылки, встроенный код, выбранный элемент почти во всех диалогах, рамка редактора в фокусе, значки Plan/«running», индикаторы загрузки |
| `accent` | `#5BC0BE` | `#00838F` | Дополнительный акцент: префикс подтверждения `▶`, блок кода устройства, заполнитель изображения, панели BTW и очереди, импорт реестра |
| `text` | `#E0E0E0` | `#1A1A1A` | Основной текст: содержимое диалогов, заголовки задач, название модели в нижней панели, заголовки Markdown, маркеры сообщений ассистента и инструментов, маркеры списков |
| `textStrong` | `#F5F5F5` | `#1A1A1A` | Выделенный и полужирный текст: диалоги ввода, сообщения о состоянии |
| `textDim` | `#888888` | `#454545` | Второстепенный приглушённый текст: размышления, подсказки, описания, выполненные задачи, цитаты Markdown, строка состояния внизу |
| `textMuted` | `#6B6B6B` | `#5F5F5F` | Самый бледный текст: счётчики, сведения о прокрутке, описания, URL ссылок Markdown, рамки блоков кода |
| `border` | `#5A5A5A` | `#737373` | Рамки панелей и редактора, горизонтальные линии Markdown |
| `borderFocus` | `#E8A838` | `#92660A` | Рамка фокуса или привлечения внимания; сейчас используется только в панели подтверждения |
| `success` | `#4EC87E` | `#0E7A38` | Успешное состояние: `✓`, «enabled», завершённые операции |
| `warning` | `#E8A838` | `#92660A` | Предупреждение: значки auto/yolo, отметки устаревших данных, подсказка Plan mode |

| `diffRemovedStrong` | `#F08585` | `#B91C1C` | Изменённые слова внутри удалённой строки различий, выделенные полужирным |

## Использование Skill custom-theme

Писать JSON вручную необязательно. Выполните встроенную команду Skill `/custom-theme [дополнительный текст]`, чтобы запустить процесс создания темы: Skill поможет выбрать цвета, запишет файл в `~/.multiai/themes/`, проверит шестнадцатеричные значения и подскажет, как применить тему.

Примеры вызова:

- `/custom-theme Create a warm dark theme with amber accents.`
- `/custom-theme Make a light theme based on Solarized, but keep errors easy to see.`
- `/custom-theme Tweak my ember theme so diffs have higher contrast.`

После запуска Skill обычно спрашивает, нужна ли светлая или тёмная основа, какое настроение или палитра вам ближе и есть ли точные цвета, которые следует использовать. Если вы изменяете существующую тему, убедитесь, что Skill читает файл и создаёт резервную копию перед перезаписью.

## Создание темы

Добавьте файл `.json` в каталог тем:

- `~/.multiai/themes/`;
- или `$MULTIAI_HOME/themes/`, если задана переменная окружения `MULTIAI_HOME`.

Если каталога нет, создайте его. **Имя файла становится именем темы**: `ember.json` отображается в `/theme` как `Custom: ember`.

В минимальной теме достаточно указать только изменяемые цвета; остальные берутся из **базовой палитры** (по умолчанию `dark`):

```json
{
  "name": "ember",
  "colors": {
    "primary": "#83A598",
    "accent": "#FE8019"
  }
}
```

Поля:

- `name` (обязательное): идентификатор темы.
- `displayName` (необязательное): удобочитаемое название.
- `base` (необязательное): встроенная палитра, из которой наследуются неуказанные токены — `"dark"` (по умолчанию) или `"light"`. При создании **светлой** темы укажите `"base": "light"`, чтобы пропущенные токены оставались читаемыми на светлом фоне, иначе они будут взяты из тёмной палитры.
- `colors` (необязательное): переопределяемые цветовые токены; каждое значение — шестизначный шестнадцатеричный цвет, например `#FE8019`.

Используйте имена токенов из раздела [«Встроенные цветовые токены»](#встроенные-цветовые-токены). Все пропущенные токены берутся из выбранной базовой палитры, поэтому тема может быть неполной:

```json
{
  "name": "just-blue",
  "colors": {
    "primary": "#3B82F6",
    "roleUser": "#3B82F6"
  }
}
```

## Выбор темы

Есть два способа:

1. **Команда `/theme`** (рекомендуется): открывает список тем, где пользовательские темы показаны как `Custom: <filename>`. При каждом открытии список **заново сканирует каталог тем**, поэтому только что добавленный файл появится **без перезапуска**.
2. **`tui.toml`**: задайте в `theme` имя темы:

   ```toml
   # ~/.multiai/tui.toml
   theme = "ember"
   ```

## Что происходит при ошибках

Пользовательские темы устроены так, чтобы не мешать работе:

- **Недопустимое значение цвета** (не `#` и 6 шестнадцатеричных цифр): только эта запись молча пропускается и заменяется значением из базовой палитры; остальные цвета продолжают действовать.
- **Неизвестный токен**: игнорируется и не влияет на остальные цвета.
- **Отсутствующий файл пользовательской темы или некорректный JSON**: без сообщения используется встроенная палитра `dark`; повторной попытки с `auto` не происходит.

## Изменение активной темы

Если изменить файл **активной в данный момент** темы, изменения не загрузятся автоматически. Чтобы применить новые цвета:

- выполните `/reload-tui` — команда перезагрузит `tui.toml` и заново применит текущую тему, перечитав её файл;
- либо переключитесь в `/theme` на другую тему, а затем обратно.

::: warning Примечание
Повторный выбор **той же** темы в `/theme` не перезагружает её: вы увидите сообщение «Theme unchanged». Чтобы загрузить изменения активной темы, используйте один из двух способов выше.
:::
