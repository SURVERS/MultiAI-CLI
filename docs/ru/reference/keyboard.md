# Сочетания клавиш

Интерактивный режим TUI в MultiAI CLI поддерживает набор сочетаний клавиш. Они сгруппированы по контексту использования: общий ввод, переключение режимов, потоковый вывод, управление выводом инструментов, панель подтверждения и навигация во всплывающих окнах. В любой момент введи `/help` в TUI, чтобы открыть встроенный справочник сочетаний клавиш.

## Общие сочетания клавиш

В поле ввода всегда доступны следующие клавиши:

| Сочетание клавиш | Действие |
| --- | --- |
| `Enter` | Отправить текущий ввод |
| `Shift-Enter` / `Ctrl-J` | Вставить перенос строки |
| `↑` / `↓` | Просмотреть историю ввода |
| `Esc` | Закрыть всплывающее окно / отменить автодополнение / прервать потоковый вывод или сжатие контекста |
| `Ctrl-C` | Прервать текущий потоковый вывод или очистить поле ввода |
| `Ctrl-D` | Выйти из MultiAI CLI, если поле ввода пусто |
| `Ctrl-T` | Развернуть или свернуть список задач, если он отображается не полностью |

Нажатие `Ctrl-C` **во время потокового вывода** отменяет его сразу — повторное подтверждение не требуется.

**Выход из программы** (нажатие `Ctrl-C` при пустом поле ввода или `Ctrl-D`) требует двойного нажатия: после первого в строке состояния появляется подсказка, а второе нажатие той же клавиши завершает программу. Нажатие любой другой клавиши между ними сбрасывает ожидание подтверждения.

## Переключение режимов

| Сочетание клавиш | Действие |
| --- | --- |
| `Shift-Tab` | Включить или выключить Plan mode |
| `!` | Перейти в режим оболочки (в пустом поле ввода) |

Нажми `Shift-Tab`, чтобы включить или выключить Plan mode. В этом режиме агент отдаёт приоритет инструментам только для чтения при исследовании и планировании и может записывать данные в текущий файл плана; на `Bash` распространяются текущий режим разрешений и обычные правила, без отдельного подтверждения из-за Plan mode. Простое переключение не создаёт пустой файл плана. Чтобы выйти из Plan mode, снова нажми `Shift-Tab`.

Введи `!` в пустом поле, чтобы перейти в режим оболочки и выполнять команды терминала напрямую; пока команда выполняется, нажми `Ctrl-B`, чтобы перенести её в фоновую задачу. Подробнее см. в разделе [«Взаимодействие и ввод»](../guides/interaction.md#shell-mode).

## Ввод и редактирование

| Сочетание клавиш | Действие |
| --- | --- |
| `Ctrl-G` | Изменить текущий ввод во внешнем редакторе |
| `Ctrl-V` | Вставить изображение или видео из буфера обмена (Unix / macOS) |
| `Alt-V` | Вставить изображение или видео из буфера обмена (Windows) |
| `Ctrl--` | Отменить действие |
| `Esc` `Esc` | Открыть меню отмены (двойное нажатие в состоянии ожидания) |

При нажатии `Ctrl-G` внешний редактор выбирается в следующем порядке:

1. Редактор, настроенный командой `/editor`
2. Переменная окружения `$VISUAL`
3. Переменная окружения `$EDITOR`

После сохранения и выхода изменённое содержимое заменяет текст в поле ввода; если выйти без сохранения, ввод не изменится.

При вставке изображения или видео в поле ввода отображается заполнитель — сами медиаданные отправляются модели вместе с сообщением. Сначала читается системный буфер обмена; в Linux проверяются Wayland и X11, а в WSL для чтения буфера Windows дополнительно используется PowerShell.

## Во время потокового вывода

Пока идёт потоковый вывод, поле ввода продолжает принимать текст и поддерживает дополнительные действия:

| Сочетание клавиш | Действие |
| --- | --- |
| `Ctrl-S` | Направить текущий ввод прямо в выполняющийся ход |
| `Esc` | Прервать текущий потоковый вывод |
| `Ctrl-C` | Прервать текущий потоковый вывод |

После нажатия `Ctrl-S` модель увидит сообщение в ближайшей точке, где выполнение можно прервать, не дожидаясь завершения текущего хода.

## Вывод инструментов

| Сочетание клавиш | Действие |
| --- | --- |
| `Ctrl-O` | Развернуть или свернуть вывод инструментов и сводки сжатия |

Если в истории есть свёрнутые результаты вызовов инструментов, нажми `Ctrl-O`, чтобы переключиться между свёрнутым и развёрнутым представлением. После сжатия контекста та же комбинация показывает или скрывает сводку в блоке сжатия.

## Панель подтверждения

Когда агент инициирует вызов инструмента, требующий подтверждения, TUI показывает панель подтверждения. Полный процесс описан в разделе [«Взаимодействие и ввод»](../guides/interaction.md#审批流程). Внутри панели доступны следующие клавиши:

| Сочетание клавиш | Действие |
| --- | --- |
| `↑` / `↓` | Перемещать курсор между вариантами |
| `Enter` | Подтвердить выбранный вариант |
| `1` ~ `9` | Сразу выбрать вариант с соответствующим номером |
| `Esc` / `Ctrl-C` / `Ctrl-D` | Отклонить текущий запрос |
| `Ctrl-E` | Развернуть или свернуть полное содержимое, если панель содержит diff или предпросмотр файла |
| `Ctrl-O` | Переключить свёрнутое состояние вывода других инструментов |

После подтверждения вариантов, требующих обратной связи (например, «Отклонить» или «Пересмотреть»), панель переходит в режим ввода комментария: введи текст и нажми `Enter`, чтобы отправить его; нажми `Esc`, чтобы выйти из ввода и вернуться к списку вариантов.

## Режим всплывающего окна

Открыв панель справки командой `/help`, используй следующие клавиши для навигации и закрытия:

| Сочетание клавиш | Действие |
| --- | --- |
| `↑` / `↓` | Прокрутить на одну строку |
| `PageUp` / `PageDown` | Прокрутить на 10 строк |
| `Esc` / `Enter` / `q` / `Q` | Закрыть панель |
