# Взаимодействие и ввод

MultiAI CLI работает как интерактивный TUI (терминальный пользовательский интерфейс), состоящий из трёх основных частей: поля ввода, области беседы и строки состояния. На этой странице описано, как вводить текст, вставлять медиафайлы, работать с подтверждениями и переключать режимы.

## Основы работы с полем ввода

Поле ввода принимает текст в свободной форме. Нажмите `Enter` для отправки, а `Shift-Enter` или `Ctrl-J` — для новой строки. Когда поле пусто, нажимайте `↑` / `↓`, чтобы просматривать историю ввода для текущего рабочего каталога, включая предыдущие команды оболочки.

**Выход из CLI**: нажмите `Ctrl-D` при пустом поле ввода, дважды нажмите `Ctrl-C` во время ожидания или введите `/exit`. Нажатие `Ctrl-C` или `Esc` во время потокового вывода прерывает текущий ход, но не закрывает программу.

## Вставка изображений и видео

MultiAI CLI позволяет вставлять изображения и видео прямо в поле ввода, чтобы обсуждать снимки экрана, макеты интерфейса, архитектурные схемы или демонстрации кода без предварительной загрузки и преобразования файлов.

**Ввод видео — отличительная возможность MultiAI CLI**: можно вставить видеоклип и попросить модель проанализировать его содержимое, логику интерфейса или показ кода.

Как вставлять:

- **macOS / Linux**: `Ctrl-V`
- **Windows**: `Alt-V`

После вставки в поле появляется заполнитель, который можно редактировать как обычный текст; при отправке он заменяется фактическим содержимым. Обычный текст из буфера вставляется стандартным способом. Поддержка медиа зависит от мультимодальных возможностей текущей модели (`image_in` / `video_in`); при входе в учётную запись MultiAI CLI она включена по умолчанию.

## Команды с косой чертой

Всё, что начинается с `/`, считается командой с косой чертой. При вводе `/` открывается меню автодополнения, которое фильтруется по мере ввода; нажмите `Esc`, чтобы закрыть его. Если совпадений нет, ввод отправляется агенту как обычное сообщение.

Активные [Agent Skills](../customization/skills.md) автоматически регистрируются как команды с косой чертой: обычные внешние Skills вызываются через `/skill:<name>`, внешние вложенные Skills отображаются как команды с точкой, например `/parent.child`, а встроенные Skills появляются на панели непосредственно как `/<name>`. Если имя внешнего Skill не конфликтует с системной командой, префикс `skill:` можно опустить и ввести сразу `/<name>`.

Некоторые команды доступны только во время ожидания агента — перед их использованием нужно нажать `Esc`, чтобы прервать потоковый вывод или сжатие контекста. Команды переключения режимов и запросов, например `/yolo`, `/plan`, `/help` и `/btw`, доступны всегда. Полный список приведён в [справочнике команд с косой чертой](../reference/slash-commands.md).

## Ссылки на файлы

Введите `@`, чтобы вызвать автодополнение путей. При выборе путь вставляется в сообщение в относительном виде, а агент загружает содержимое файла при чтении сообщения. Ссылки на файлы работают как в каталогах git, так и вне них; предложения каталогов заканчиваются `/`, чтобы можно было продолжить ввод пути. Если быстрый помощник поиска ещё загружается, MultiAI CLI использует обычное сканирование файловой системы. Скрытые пути доступны, но `.git` исключён из предложений.

> Ссылки `@` и команды с косой чертой — разные механизмы: `@` передаёт агенту контекст файла, а `/` вызывает встроенные возможности или Skills. Символ `/` после начального пробела считается обычным текстом и не открывает меню команд.

## Процесс подтверждения

Когда агент вызывает инструмент с побочными эффектами — изменяет файлы или запускает команды, — TUI показывает панель запроса подтверждения. В YOLO mode подтверждения для обычных вызовов инструментов не запрашиваются, как и для записи в файлы плана в Plan mode.

Выберите вариант стрелками и нажмите `Enter` либо сразу нажмите `1`, `2` или `3`. `Esc`, `Ctrl-C` и `Ctrl-D` равнозначны отказу.

Обычно панель содержит вариант **Разрешить для этого сеанса**: после его выбора вызовы того же вида автоматически разрешаются до конца сеанса. Постоянные разрешающие и запрещающие правила задаются в [файлах конфигурации](../configuration/config-files.md#permission).

## Переключение режимов

### Plan mode

В Plan mode агент сначала выводит план действий и ждёт подтверждения, прежде чем изменять файлы. Это полезно для сложных или рискованных задач.

- Переключение: `Shift-Tab` или `/plan`
- Очистка текущего плана: `/plan clear` (только во время ожидания)

После подготовки плана агент приостанавливается: план можно одобрить, отклонить или попросить доработать. Для выхода из Plan mode требуется подтверждение, даже если включён YOLO mode. Исключение — Auto mode: выход из плана подтверждается автоматически и помечается в истории как «Auto-approved».

### YOLO / Auto mode

**YOLO mode** (`/yolo`) автоматически подтверждает обычные вызовы инструментов и подходит для пакетных задач, безопасность которых вам известна. Для чувствительных действий — доступа к таким файлам, как `.env` или ключи SSH, и выхода из Plan mode — подтверждение всё равно требуется; агент также может задавать вопросы.

**Auto mode** (`/auto`) предназначен для полностью автономной работы: все подтверждения инструментов обрабатываются автоматически, включая чувствительные файлы и выход из плана, а агент не задаёт вопросов и принимает все решения самостоятельно.

::: warning
YOLO mode не запрашивает подтверждение записи файлов и выполнения команд. Используйте его только в рабочих каталогах, которым доверяете.
:::

### Режим оболочки

Режим оболочки позволяет выполнять команды терминала, не покидая беседу. Результат команды добавляется в контекст беседы, поэтому агент видит его в следующих ходах.

- Вход: введите `!` в пустом поле или вставьте команду, начинающуюся с `!`.
- Выход: нажмите `Backspace` или `Esc` в пустом поле; после отправки команды возврат в обычный режим также происходит автоматически.
- Фоновое выполнение: пока команда работает, нажмите `Ctrl+B`, чтобы перенести её в фоновую задачу.
- Вызов предыдущих команд: в режиме оболочки при пустом поле нажимайте `↑`; выбранная команда остаётся в режиме оболочки и снова выполняется как команда.

В режиме оболочки слева в поле ввода отображается приглашение `!`, а рамка становится фиолетовой. Например, можно выполнить `!gh auth login`, чтобы войти в GitHub CLI без нового терминала, и после этого MultiAI сможет использовать `gh`.

## Во время потокового вывода

Поле ввода остаётся доступным, пока агент размышляет или вызывает инструменты, и поддерживает дополнительные действия:

- **`Ctrl-S`**: немедленно добавить содержимое поля в выполняющийся ход, не дожидаясь его завершения
- **`Esc` / `Ctrl-C`**: прервать текущий ход
- **`Ctrl-O`**: глобально свернуть или развернуть вывод инструментов и сводки сжатия

## Внешний редактор

Нажмите `Ctrl-G`, чтобы передать содержимое поля ввода во внешний редактор. После сохранения и закрытия текст вернётся в поле; если закрыть без сохранения, исходный текст сохранится. Это удобно для больших блоков или текста со сложным форматированием.

Приоритет редакторов: настройка `/editor` → переменная окружения `$VISUAL` → переменная окружения `$EDITOR`. Если ничего не задано, сначала выполните `/editor` и выберите редактор по умолчанию.
