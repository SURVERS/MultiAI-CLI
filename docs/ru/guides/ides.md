# Использование MultiAI CLI в IDE

MultiAI CLI поддерживает интеграцию с IDE через [Agent Client Protocol (ACP)](https://agentclientprotocol.com/), позволяя работать с AI-помощником для программирования прямо в редакторе.

## Предварительные требования

Перед настройкой IDE убедитесь, что MultiAI CLI установлен и вход выполнен.

Адаптер ACP доступен как подкоманда `multiai acp`. IDE запускает её как дочерний процесс и обменивается данными через stdin/stdout по JSON-RPC. При каждом создании сеанса в IDE CLI использует уже существующее состояние аутентификации — повторный вход не нужен.

::: tip Примечание о пути
Дочерние процессы, запущенные из графического интерфейса IDE в macOS, обычно **не** наследуют `PATH` оболочки терминала. Если `multiai` находится не в системном каталоге наподобие `/usr/local/bin`, укажите абсолютный путь в конфигурации IDE. Чтобы найти текущий путь, выполните в терминале `which multiai`.
:::

## Использование MultiAI CLI в Zed

[Zed](https://zed.dev/) — современный редактор со встроенной поддержкой ACP.

Добавьте в файл конфигурации Zed `~/.config/zed/settings.json` следующее:

```json
{
  "agent_servers": {
    "MultiAI CLI": {
      "type": "custom",
      "command": "multiai",
      "args": ["acp"],
      "env": {}
    }
  }
}
```

Поля конфигурации:

- `type`: фиксированное значение `"custom"`;
- `command`: путь к исполняемому файлу MultiAI CLI. Если `multiai` отсутствует в `PATH`, укажите полный путь (например, `/Users/you/.local/bin/multiai`);
- `args`: аргументы запуска. Подкоманда `acp` переводит CLI в режим ACP;
- `env`: дополнительные переменные окружения; обычно оставляйте объект пустым. Zed автоматически добавляет стандартное окружение.

После сохранения откройте новую беседу на панели Agent в Zed: редактор запустит подпроцесс ACP `MultiAI CLI` с указанной конфигурацией. Серверы MCP, объявленные в разделе `agent_servers` Zed, также передаются в multiai по протоколу ACP.

## Использование MultiAI CLI в IDE JetBrains

IDE JetBrains (IntelliJ IDEA, PyCharm, WebStorm и другие) поддерживают ACP через плагин AI chat.

Если у вас нет подписки JetBrains AI, включите `llm.enable.mock.response` в Registry, чтобы получить доступ к панели AI chat в сценариях только с ACP. Дважды нажмите Shift и найдите «Registry», чтобы открыть её.

В меню панели AI chat нажмите **Configure ACP agents** и добавьте следующую конфигурацию:

```json
{
  "agent_servers": {
    "MultiAI CLI": {
      "command": "~/.local/bin/multiai",
      "args": ["acp"],
      "env": {}
    }
  }
}
```

JetBrains строго проверяет поле `command` — всегда указывайте **абсолютный путь**, который можно получить командой `which multiai` в терминале. После сохранения `MultiAI CLI` появится в списке агентов AI chat.

## Использование MultiAI CLI в Paseo

[Paseo](https://paseo.sh/) — самостоятельно развёртываемый оркестратор, который запускает CLI агентов и следит за ними с компьютера, из веб-интерфейса и с мобильного устройства. Он подключается к MultiAI CLI по ACP так же, как IDE.

Выберите **MultiAI CLI** во встроенном каталоге провайдеров ACP в Paseo или добавьте пользовательский провайдер в `~/.paseo/config.json`:

```json
{
  "agents": {
    "providers": {
      "multiai": {
        "extends": "acp",
        "label": "MultiAI CLI",
        "command": ["multiai", "acp"]
      }
    }
  }
}
```

Универсальный адаптер ACP в Paseo не управляет входом, поэтому сначала выполните вход в терминале (см. [Предварительные требования](#предварительные-требования)), иначе создание сеанса завершится ошибкой `Authentication required`.

## Устранение неполадок

- **Сеанс сразу отключается / IDE показывает «agent exited»**: обычно указан неверный путь `command` или не выполнен вход. Сначала запустите `multiai acp` в терминале: если процесс ожидает данные из stdin, сам CLI исправен и проблема в конфигурации IDE; если он сразу завершается с ошибкой, следуйте сообщению об ошибке (чаще всего нужно выполнить `/login`).
- **IDE показывает «auth required»**: у CLI нет пригодного токена аутентификации. Закройте IDE, запустите `multiai` в терминале и выполните вход, затем перезапустите IDE.
- **Инструменты MCP не видны**: сверьтесь с таблицей возможностей в [справочнике `multiai acp`](../reference/multiai-acp.md), чтобы убедиться, что настроенный в IDE транспорт MCP поддерживается. Сейчас адаптер ACP в MultiAI CLI поддерживает транспорты `http`, `stdio` и `sse`; серверы MCP с транспортом `acp` молча отбрасываются, а в журнал записывается предупреждение.
