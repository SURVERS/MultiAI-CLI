# Начало работы

## Что такое MultiAI CLI

MultiAI CLI — это AI-агент, работающий в терминале. Он помогает решать задачи разработки и выполнять повседневные операции в терминале: читать и изменять код, запускать команды оболочки, искать файлы, загружать веб-страницы, а также самостоятельно планировать и корректировать следующие шаги по мере работы с учётом обратной связи.

Он подходит для таких сценариев:

- **Написание и изменение кода**: реализация новых возможностей, исправление ошибок, рефакторинг
- **Изучение проекта**: исследование незнакомой кодовой базы и ответы на вопросы об архитектуре и реализации
- **Автоматизация задач**: пакетная обработка файлов, запуск сборок и тестов, последовательный запуск нескольких скриптов

CLI написан на TypeScript, распространяется через npm и работает на Node.js.

## Установка

Установите пакет npm глобально или скачайте нативную сборку из GitHub Releases.

::: tip Перед установкой
MultiAI CLI — полностью интерактивное TUI-приложение. Для лучшего отображения запускайте его в терминале с поддержкой полного цвета и лигатур, например [Kitty](https://sw.kovidgoyal.net/kitty/) или [Ghostty](https://ghostty.org/).
:::

### Установка через npm

Требуется Node.js 24.15.0 или новее:

```sh
node --version
npm install -g multiai-cli
```

Или с помощью pnpm:

```sh
pnpm add -g multiai-cli
```

Нативные сборки доступны на [странице GitHub Releases](https://github.com/SURVERS/MultiAI-CLI/releases).

> В Windows перед первым запуском установите [Git for Windows](https://gitforwindows.org/). MultiAI CLI использует входящий в комплект Git Bash как среду оболочки; если Git Bash установлен в нестандартном месте, задайте в `MULTIAI_SHELL_PATH` абсолютный путь к `bash.exe`.

## Обновление и удаление

После установки убедитесь, что исполняемый файл готов к работе:

```sh
multiai --version
```

**Обновление**: выполните `multiai upgrade` — CLI проверит наличие новой версии и предложит варианты обновления. Выберите `Install update now`, чтобы обновиться с учётом текущего источника установки. Также можно обновиться напрямую через менеджер пакетов:

```sh
npm install -g multiai-cli@latest
```

**Удаление**: удалите скачанный нативный исполняемый файл либо пакет npm:

```sh
npm uninstall -g multiai-cli
```

## Первый запуск

Перейдите в каталог проекта и запустите `multiai`, чтобы открыть интерактивный интерфейс:

```sh
cd your-project
multiai
```

Чтобы выполнить одну инструкцию без входа в интерактивный интерфейс, используйте `-p`:

```sh
multiai -p "Take a look at this project's directory structure"
```

Чтобы возобновить предыдущий сеанс, добавьте `-c`:

```sh
multiai -c
```

При первом запуске нужно настроить источник API. В интерактивном интерфейсе введите `/login`, чтобы начать вход:

```
/login
```

`/login` открывает в браузере поток MultiAI OAuth с Authorization Code и PKCE. CLI слушает только временный порт на `127.0.0.1`. Если браузер использовать нельзя, выберите резервный вход по коду устройства или выполните `multiai login --device`.

Рабочие сборки содержат публичный идентификатор клиента, выпущенный для нативного приложения. В сборках для разработки и тестовой среды его можно переопределить через `MULTIAI_OAUTH_CLIENT_ID`. Никогда не настраивайте секрет клиента в CLI.

Для просмотра или очистки учётной записи используйте `/account` и `/logout` либо команды `multiai account` и `multiai logout`.

::: tip Другие AI-провайдеры
Чтобы подключить Kimi, Anthropic, OpenAI, Google или другого внешнего провайдера, отредактируйте `~/.multiai/config.toml` и настройте его ключ API. Подробнее см. в разделе [Провайдеры и модели](../configuration/providers.md).
:::

Поведение системного хранилища ключей, срок действия токенов, удаление учётной записи, изменения профиля, ошибки квоты и точные настройки приложения `multiai.store` описаны в разделе [Учётная запись и OAuth](./account-and-oauth.md).

## Ваша первая беседа

После входа опишите задачу на естественном языке. Для начала полезно дать MultiAI CLI изучить проект:

```
Изучи структуру каталогов этого проекта и кратко объясни назначение каждого каталога.
```

MultiAI CLI автоматически вызывает инструменты чтения файлов, поиска и другие инструменты, чтобы изучить нужные материалы перед ответом. По умолчанию операции только для чтения выполняются автоматически без подтверждения. Перед изменением файлов или запуском команд оболочки запрашивается подтверждение.

Можно сразу описать более конкретную задачу:

```
Добавь в src/utils функцию, которая преобразует любую строку в kebab-case, и напиши для неё модульный тест.
```

MultiAI CLI спланирует шаги, изменит код, запустит тесты и сообщит, что сделал на каждом этапе.

::: tip Не знаете, что делать? Введите `/help`
В любой момент введите `/help`, чтобы открыть встроенную панель команд и сочетаний клавиш. Используйте `↑`/`↓` для навигации и `Esc` для закрытия. Для выхода введите `/exit`, дважды нажмите `Ctrl-C` или нажмите `Ctrl-D` при пустом поле ввода.
:::

## Основные команды и сочетания клавиш

Для начала достаточно знать следующее:

**Команды сеанса**

| Команда | Описание |
| --- | --- |
| `/new` | Начать новый сеанс и очистить текущий контекст |
| `/sessions` | Просмотреть историю сеансов и выбрать сеанс для возобновления |
| `/model` | Сменить текущую модель |
| `/compact` | Вручную сжать контекст и освободить токены |
| `/fork` | Создать ответвление текущего сеанса, сохранив историю, но продолжив независимо |

**Часто используемые сочетания клавиш**

| Сочетание | Описание |
| --- | --- |
| `Esc` | Прервать потоковый вывод / закрыть всплывающее окно |
| `Ctrl-C` | Прервать вывод; во время ожидания нажать дважды для выхода |
| `Shift-Tab` | Переключить Plan mode |
| `Ctrl-S` | Добавить сообщение во время потокового вывода, не дожидаясь завершения текущего ответа |
| `Ctrl-O` | Свернуть / развернуть вывод инструментов и сводки сжатия |

Полный список можно открыть командой `/help` или найти в разделах [Справочник команд с косой чертой](../reference/slash-commands.md) и [Сочетания клавиш](../reference/keyboard.md).

## Где хранятся данные

По умолчанию MultiAI CLI хранит локальные данные в `~/.multiai/`: файлы конфигурации, записи сеансов, журналы и кэш обновлений. Чтобы перенести их, укажите новый путь в переменной окружения `MULTIAI_HOME`. Полная структура каталогов описана в разделах [Расположение данных](../configuration/data-locations.md) и [Переменные окружения](../configuration/env-vars.md).
