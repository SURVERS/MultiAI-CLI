# Check MultiAI CLI docs

Use the current MultiAI CLI documentation as the source of truth:

```
https://github.com/SURVERS/MultiAI-CLI/tree/main/docs
```

Fetch the relevant page before answering. Prefer the OAuth/account guide for sign-in,
token, balance, scope, or account-lifecycle questions. Prefer configuration and reference
pages for commands, environment variables, providers, models, and data locations.

If the published documentation is unavailable or does not cover the question, say which
part could not be verified. Do not substitute old Kimi Code product documentation and do
not invent configuration keys, command names, model IDs, or OAuth behavior.
